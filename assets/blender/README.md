# Blender assets

Every 3D asset of the office is generated by the Python scripts in this folder: never edit the GLB
files by hand.

```sh
# Build every prop and export apps/web/public/models/props.glb
/Applications/Blender.app/Contents/MacOS/Blender --background --python assets/blender/build_props.py

# Render a contact sheet of some props (no export) to review them without the Blender UI
/Applications/Blender.app/Contents/MacOS/Blender --background --python assets/blender/build_props.py -- \
  --only desk,office_chair,monitor --preview /tmp/props.png
```

## Conventions

- Units are meters; each prop's origin is at its bottom center.
- The front of a prop faces Blender −Y, which becomes +Z in glTF / three.js.
- Props are built from beveled primitives with palette materials (`lib/kit.py`). At export, palette
  colors are baked into vertex colors and faces are regrouped into five shared class materials
  (`matte`, `glossy`, `metal`, `emissive`, `glass`), so each prop costs 1–3 draw calls and can be
  instanced in the browser.
- Adding a prop: write a builder returning `join(parts, "<name>")` in `props/*.py`, register it in
  that module's `PROPS`, add the name to `PROP_NAMES` in `apps/web/src/world/props/propLibrary.ts`,
  then place it in `apps/web/src/world/decor.ts`.
